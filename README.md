# FedEx Logistics Performance Analysis

## Project Type
Exploratory Data Analysis (EDA)

## Project Overview

This project analyzes FedEx logistics shipment data to understand delivery performance, shipment delays, shipment modes, fulfilment methods, countries, vendors, and logistics costs.

The analysis focuses on identifying factors that influence delivery performance and areas where logistics operations can be improved.

## Business Objectives

- Improve on-time delivery performance
- Identify shipment modes and locations with delivery issues
- Understand fulfilment and vendor performance
- Analyze shipment weight and logistics costs
- Improve delivery planning and operational efficiency

## Dataset

The dataset contains historical FedEx shipment and delivery information.

- Rows: 10,324
- Columns: 33
- Domain: Logistics & Supply Chain

Key information includes:

- Country
- Shipment Mode
- Managed By
- Fulfilment Method
- Vendor
- Product Group
- Delivery Dates
- Shipment Quantity
- Weight
- Freight Cost
- Insurance Cost

## Analysis Performed

The project includes:

- Data understanding
- Data cleaning
- Missing value analysis
- Univariate analysis
- Bivariate analysis
- Multivariate analysis
- Delivery performance analysis
- Shipment mode analysis
- Country analysis
- Cost analysis
- Correlation analysis
- Business insights and recommendations

## Key Conclusion

The analysis shows that overall delivery performance is strong, but some shipment modes, countries, fulfilment methods, and operational factors require attention.

FedEx can improve logistics performance by reducing delivery delays, improving delivery planning, monitoring weaker-performing areas, and better managing high-weight and high-value shipments.
